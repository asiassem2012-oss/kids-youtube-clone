# 🎬 YouTube Clone - موقع قصص الأطفال

موقع لمشاهدة قصص الأطفال والفيديوهات التعليمية، مع نظام تسجيل دخول، لوحة تحكم مشرف، وإعلانات مخصصة.

## ✨ المميزات
- 📹 مشاهدة فيديوهات YouTube مدمجة
- 🔐 تسجيل الدخول بحساب Google (Firebase Auth)
- 👑 لوحة تحكم للمشرف (إضافة/حذف/تعديل فيديوهات)
- ⏰ نظام رقابة أبوية (تحديد وقت المشاهدة)
- 📱 تصميم متجاوب مع جميع الأجهزة

## 🛠️ التقنيات المستخدمة
- HTML5 + CSS3 + JavaScript
- Firebase (Authentication + Firestore)
- Netlify (استضافة)
- YouTube Embed API
